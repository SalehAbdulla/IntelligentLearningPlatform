## Where the mockups themselves live

The wireframes are **in the Figma file**, not in this folder as images, so they
cannot drift out of sync with the high-fidelity prototype:

| Figma page | Contents |
|---|---|
| `5 · Low-Fi Wireframes` | **106 wireframes**, 4 per row, each with **numbered callout badges** and a **legend panel** naming every element and its function |
| `2 · Flow Overview` | the global **navigation map** plus **15 per-feature flow diagrams** |

Link: `deliverables/prototype/figma-link.txt`.

## Why the wireframes are drawn in Figma rather than on paper

`docs/08-RUBRIC-COVERAGE-MATRIX.md` row **c5** already commits to this: *"Figma
(low-fidelity mode), same file as the prototype, so the low-fi and hi-fi stay in
sync by construction."* The brief permits any method (paper, Draw.io, Figma,
Canva); drawing them in Figma is a deliberate efficiency choice with a real
benefit, because a change to a screen changes its wireframe too.
