## Confusions, in the participant's own words

One row per distinct confusion. **Quote the participant.** If three participants hit the same
problem, that is one row with three participants listed — and it is the strongest finding the test
can produce.

**Severity**, using the standard three levels:

| Level | Meaning | Response |
|---|---|---|
| **High** | Blocks the task, or the participant would give up | Fix before the prototype is frozen |
| **Medium** | Slows the task, or causes a wrong first attempt | Fix if the fix is small |
| **Low** | Noticed, but no effect on completing the task | Record, and fix if free |

Anything that affected the session itself — the device overheating, a build reinstall, a participant
arriving late, a simulated state that behaved oddly. **These belong in the write-up**, because they
are part of the honest record of how the test ran.
